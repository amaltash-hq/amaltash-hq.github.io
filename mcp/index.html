Finance calculator MCP server

Amaltash Investment & Retirement Calculators. Compound interest, investment, retirement, CD, S&P 500 and DCA calculators with charts.

  • Public
  • Read-only
  • No sign-in
  • Streamable HTTP

Server URL

https://tools.amaltash.com/mcp

It has 13 calculators and a list of the stocks and funds it knows. It cannot trade or move money.

Add it in Claude

  1. In Claude, open Settings, then Connectors.
  2. Add a custom connector.
  3. Paste https://tools.amaltash.com/mcp. You don't need to sign in.
  4. Ask a money question, like "What does $10,000 grow to at 5% in 10 years?"

Full guide and example questions

Claude Code plugins

Add the Amaltash marketplace, then install a plugin:

/plugin marketplace add amaltash-hq/mcp
/plugin install calculators@amaltash
/plugin install trading@amaltash

Or add only the server:

claude mcp add --transport http amaltash-calculators https://tools.amaltash.com/mcp

Source and docs: github.com/amaltash-hq/mcp.
