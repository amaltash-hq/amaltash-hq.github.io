# amaltash-hq.github.io

Source for the Amaltash developer site: https://amaltash-hq.github.io

Plain static HTML and CSS. No build step, no tracking scripts. GitHub Pages serves `main` from the root.

- `index.html` - home
- `calculators/` - calculators by topic
- `mcp/` - MCP server setup
- `assets/` - styles, images

Main site: https://amaltash.com. MCP server and plugins: https://github.com/amaltash-hq/mcp
